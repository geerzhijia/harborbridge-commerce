# Company agent operating contract
This repository is the portable source of truth. The owner is the final decision maker. Read README.md and policies/authority.md before work. Agent role files are prompts, not evidence of running agents.

All tasks begin pending owner approval, including research. Drafting this initial repository is authorized. Specialists report to CEO; CEO submits recommendations to owner. Do not spawn, schedule, contact anyone, transact, publish, change accounts or use credentials without the relevant explicit approval. Repository bookkeeping and preparing approval packets are allowed. An approved task permits only its recorded scope; external actions require separate approval.

Save artifacts, sources and checkpoints. Resume from the ledger and saved artifacts; never rely on chat memory alone. No secrets or unnecessary personal data in Git. Use permitted APIs/manual evidence and follow access terms. Every report must disclose unavailable sources and uncertainty. Role and authority changes require owner approval. No automatic promotion to CEO autonomy.
