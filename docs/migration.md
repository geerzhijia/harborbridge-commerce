# Migration and restart
Portable formats: Markdown role prompts/reports, JSON configuration/checkpoints/tasks and JSONL event history. No vendor conversation IDs are required. `context ROLE` assembles the contract, authority, company config, role prompt, tasks and checkpoint for any model. Artifacts remain files; destination tools must explicitly load linked reports and inspect event history when required. Model context limits require selective loading, never silent deletion of source records.

Export produces a timestamped ZIP manifest with SHA-256 file hashes and all operational files including reports/checkpoints/events. It excludes Git metadata, caches, environment files and credential directories. Keep exports private; operational data can still be sensitive. Copy the ZIP to the destination, verify manifest hashes before opening, inspect for unsafe content, extract into an empty directory and run `python3 tools/company.py status`. Do not overwrite newer work. Read the latest checkpoint and reports, reconcile approvals, then resume the next approved action. Reconnect secrets and platform permissions separately; exports confer no external account authority.

Before export finish current writes and use one writer only. This starter is intended for a single local operator; concurrent agents need a transactional ledger, locking, authenticated approvals and tool-level enforcement before production. Events are append-only by convention on local disk, not tamper-proof. Back up both operational files and Git separately. A model replacement changes only the adapter/context loading; domain prompts, evidence and approval policy remain in this repo.
